# 우리 캘린더 — 실제 배포용 설정 가이드

이메일+비밀번호 회원가입, 실시간 동기화가 되는 공유 캘린더입니다.
백엔드는 **Supabase**(오픈소스 Firebase 대안, 무료 티어 제공)를 사용합니다.

파일 구성:
- `supabase-schema.sql` — 데이터베이스 테이블 + 보안 정책(RLS)
- `index.html` — 회원가입/로그인/캘린더 전체가 들어있는 앱 파일 (호스팅만 하면 됨)

---

## 1. Supabase 프로젝트 만들기

1. https://supabase.com 접속 → 무료 계정 생성 → **New Project**
2. 프로젝트 이름, 데이터베이스 비밀번호(꼭 기억해두세요), 가까운 리전 선택 후 생성 (1~2분 소요)

## 2. 데이터베이스 테이블 만들기

1. 왼쪽 메뉴에서 **SQL Editor** 클릭
2. `supabase-schema.sql` 파일 내용 전체를 복사해서 붙여넣기
3. **Run** 클릭 → 에러 없이 완료되면 성공

## 3. 이메일 인증 설정 확인

1. 왼쪽 메뉴 **Authentication → Providers → Email**이 켜져 있는지 확인 (기본값 On)
2. 테스트를 빠르게 하고 싶다면 같은 화면에서 **Confirm email**(이메일 인증 필수 여부) 옵션을 꺼두면,
   가입 즉시 이메일 인증 없이 로그인할 수 있습니다. (실제 서비스로 운영할 땐 켜두는 걸 권장해요)

## 4. API 키 확인

1. 왼쪽 메뉴 **Project Settings → API**
2. **Project URL**과 **anon public key** 두 값을 복사

## 5. index.html에 키 입력

`index.html` 파일을 열어서 아래 부분을 본인 값으로 바꿔주세요.

```js
const SUPABASE_URL = 'YOUR_SUPABASE_URL';
const SUPABASE_ANON_KEY = 'YOUR_SUPABASE_ANON_KEY';
```

## 6. 로컬에서 테스트

`index.html`을 더블클릭해서 브라우저로 열면 바로 동작합니다.
(회원가입 → 로그인 → 캘린더 만들기 → 일정 등록까지 확인해보세요)

## 7. 실제 배포하기 (아무거나 선택)

가장 쉬운 방법 — **Netlify Drop**
1. https://app.netlify.com/drop 접속
2. `index.html` 파일을 화면에 드래그 앤 드롭
3. 몇 초 후 공개 URL이 생성됩니다 (예: `https://xxxx.netlify.app`)
4. 이 링크를 함께 쓸 사람에게 공유하면 끝

다른 선택지: Vercel, GitHub Pages, Cloudflare Pages도 정적 파일 하나만 올리면 되므로 동일하게 사용 가능합니다.

## 사용 흐름

1. 회원가입 (이름 / 이메일 / 비밀번호)
2. 로그인 후 "새 캘린더 만들기" 또는 받은 "초대 코드로 참여하기"
3. 캘린더 안에서: 날짜 클릭 → 일정 등록, 멤버 칩(✎)에서 내 이름·색상 수정, 캘린더 소유자는 다른 멤버 제거 가능
4. 같은 캘린더의 다른 사람이 일정을 추가/수정하면 새로고침 없이 실시간으로 반영됩니다

## 알아두면 좋은 점

- 비밀번호는 Supabase가 자동으로 안전하게 암호화(해시)해서 저장합니다. 이 앱 코드에는 평문 비밀번호가 저장되거나 노출되지 않습니다.
- 무료 티어는 소규모 사용(가족/친구 단위)에는 충분하지만, 사용자가 많아지면 유료 플랜 검토가 필요할 수 있어요.
- 실제 이메일 발송(가입 인증, 비밀번호 재설정 메일 등)은 Supabase가 처리하지만, 무료 티어는 발송량 제한이 있습니다. 대량 발송이 필요하면 Supabase 설정에서 커스텀 SMTP를 연결하는 걸 권장합니다.
- 단일 캘린더 구조입니다. 한 사람당 캘린더 1개(사무실 공용 캘린더)에만 속하며, 로그인하면 캘린더 선택 화면 없이 바로 그 캘린더로 들어갑니다. 아직 아무 캘린더에도 속해있지 않은 계정만 "만들기/초대 코드로 참여하기" 화면을 보게 됩니다.
